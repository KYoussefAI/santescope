# SantéScope

Analyse des données de santé publique sur les accidents vasculaires cérébraux (AVC) en France.

## Objectif

Étudier la répartition géographique de l'incidence hospitalière des AVC chez les adultes en France.

Quelques questions pour orienter l'étude :

- Comment les taux d'incidence varient-ils selon les départements ?
- Quelles différences peut-on observer selon l'âge et le sexe ?
- Comment interpréter ces différences et quelles sont les limites des données disponibles ?

L'analyse sera principalement descriptive.

## Sources de données

- [Santé publique France — Incidence hospitalière des AVC](https://odisse.santepubliquefrance.fr/explore/assets/accident-vasculaire-cerebral-incidence-hospitaliere-dep/)
- [Santé publique France — Taux standardisés par département](https://odisse.santepubliquefrance.fr/explore/assets/maladies-cardio-neuro-vasculaires-taux-standardises-dep/)
- [Limites administratives des départements français](https://www.data.gouv.fr/datasets/departements-administratifs-au-1er-janvier-2024)

## Démarche

1. Étudier les données disponibles et comprendre les indicateurs.
2. Vérifier la qualité des données.
3. Analyser les taux d'incidence avec R.
4. Réaliser des graphiques et des cartes.
5. Interpréter les résultats et discuter des limites de l'étude.

Les résultats de la première analyse restent à valider.

Ce projet est destiné à l'apprentissage et ne constitue pas un outil clinique.
